Jan-Setu Architecture & Interoperability Model

CORE FOUNDATION

Jan-Setu provides a unified orchestration gateway connecting independent departmental services without creating a single centralized database. Each department owns its data, while Jan-Setu normalizes heterogeneous responses into a unified citizen record.
